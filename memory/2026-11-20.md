# 2026-11-20 — Release 1.0.45 (LWS) + 4 bugs d'auto-update corrigés

## Contexte

Session de finalisation de la release **1.0.45** : bugs vue 3D / plugin Target
corrigés, build NSIS + portable produit, mise en ligne sur l'hébergeur LWS
(`https://light-maestro.com/download/`).

## Décisions structurantes

- **Auto-update LWS via `electron-updater` provider `generic`**, pas GitHub.
  GitHub reste le dépôt de code / release de artefacts, mais le serveur de MAJ
  est l'hébergeur LWS.
- **Domaine réel** : `https://light-maestro.com/download/` (cohérent avec le
  site vitrine + l'API license). Le placeholder `ton-domaine.lws.to` est
  INTERDIT.
- **Noms d'artefacts sans espaces** (`Light-Maestro-Setup-1.0.45.exe`) —
  electron-builder transformait les espaces en tirets pour GitHub, ce qui
  faisait pointer `latest.yml` vers un fichier fantôme (404 au download).
- **`build.publish` : `generic` en PREMIER** — `app-update.yml` embarqué est
  écrit depuis `publishConfigs[0]`.

## 4 bugs trouvés en vérifiant (et corrigés)

1. `latest.yml` référençait `Light-Maestro-Setup-1.0.45.exe` alors que le
   disque contenait `Light Maestro Setup 1.0.45.exe` → auto-update en 404.
2. `app-update.yml` embarqué = `provider: github` (écrasé à chaque build par
   electron-builder) → l'app cherchait les MAJ sur GitHub, pas LWS.
3. URL placeholder `ton-domaine.lws.to` jamais remplacée.
4. `mountGroundTipText` : j'avais inversé « vers le haut » → « vers le bas »
   sur la foi d'une note antérieure, sans vérifier le moteur. Faux :
   `clampTiltZone` impose `ground → élévation [0°, +90°]`. Texte rétabli.

## Leçon structurelle : ne pas donner d'instructions d'upload "au large"

J'ai dit « copie tout le dossier `site/` » alors que seuls **2 fichiers** avaient
changé depuis le dernier upload. L'utilisateur a uploadé des dizaines de
fichiers pour rien.

**Règle** : toujours mesurer avant de lister —
`git diff --stat <commit-du-dernier-upload> HEAD -- site/`.
Le résultat EST la liste d'upload.

→ Runbook complet : `.openclaw/notes/release-runbook.md`
→ Rappel encodé dans `AGENTS.md` (section « Release / auto-update LWS »).
