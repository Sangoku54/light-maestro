FAQ — real questions from the control room

DMX & network

My USB interface is not detected

Check: FTDI driver installed, correct COM port under Universes → USB-DMX type, only one DMX software open at a time, test Blackout ON/OFF. DMX log in the app for debugging.

ArtNet / sACN: broadcast or unicast?

Unicast recommended in production (your node's IP). sACN: check universe & priority (HIGHEST wins). ArtNet: subnet 0 by default, node on 2.x.x.x or 10.x.x.x.

HTP/LTP: who wins?

HTP = Highest Takes Precedence (intensities), LTP = Latest Takes Precedence (positions/colors). Light Maestro automatically merges per channel based on its type.

Audio & Quick Show

BPM detection is wrong

Re-analyze after cutting silences / long intros, or force the BPM (tap tempo). The algorithm is adaptive but a track with variable tempo remains a challenge.

Strobe too aggressive

Safety limiter ON in Quick Show (max flashes/s), and a dedicated Strobe track with a ceiling. Live: instant Grand Master or Blackout.

.lmpreset / .lmshow / .lmproj files?

.lmpreset = audio+DMX preset, .lmshow = reusable show, .lmproj = full project (open JSON).

MIDI / OSC / MTC / 3D

MIDI Learn picks up nothing

Close other MIDI apps, select the correct input port in Preferences → MIDI, then Learn. LED feedback = MIDI output configured.

3D view not saved per preset?

Fixed in v1.0.29: camera + toggles are now serialized in .lmpreset (view3D). Update and re-save your presets.

Web Remote LAN

Enable the server in Perform → Web Remote, open the displayed URL on your phone/tablet on the same network. Real-time state push.

Projects & saving

I closed without saving

“Save & Quit / Discard” guard on close. If dirty, the app asks you.

Project unreadable on another machine

Custom fixtures are embedded in the .lmproj since v1.0.25 — no more “missing fixture”. Make sure you are on ≥1.0.25 on both sides.

Where are my files?

%APPDATA%/Light Maestro (Windows) — projects, presets, logs. Back up this folder for a full backup.
