Audio Intelligence — Show auto

Onset detection + BPM adaptatif, analyse fréquentielle (low/mid/high), détection de sections (intro/verse/chorus/drop/outro), 8 effets audio-réactifs. La musique écrit la conduite — vous affinez. Harmonie garantie : les têtes identiques exécutent le même geste, déphasé sur le rig (vague, rotation, expansion) — jamais de patterns aléatoires décalés.

Perform — Virtual Console & contrôle

MIDI Learn + feedback LED, MIDI Clock IN (le BPM suit Ableton/Triton, 24 PPQ, rend la main à l'arrêt), OSC (TouchOSC/Lemur), MTC timecode, Web Remote LAN (HTTP + push d'état).
