Configuration requise

Windows 10 22H2 / 11, 4 Go RAM (8 Go recommandé), GPU WebGL2 pour la vue 3D, port USB ou réseau pour ArtNet/sACN.

Installation en 3 étapes

1) Télécharger 2) Lancer (autoriser SmartScreen si besoin : "Plus d'infos → Exécuter quand même") 3) Brancher votre interface DMX → tester avec Blackout.

Mises à jour

L'application vérifie les nouvelles versions au démarrage et propose la mise à jour. Conservez l'ancien .exe à côté jusqu'à ce que vous ayez validé le nouveau.

Notes de version — v1.0.39

  • Copie de fixture : clic droit → Dupliquer — place automatiquement la copie à la première adresse DMX libre après la source
  • Barre de span : longueur de barre réglable (1–12 m) désormais valable pour tous les supports barre
  • Positions de musiciens persistantes : glisser un musicien sur la scène 3D garde sa position entre les pages et les rechargements de projet
  • Sans fantômes : nettoyage complet des groupes/sprites sur dépatchage et démontage
  • unpatchFixture : supprime correctement l'entrée fixturePositions
  • headingRadForPos : formule atan2 corrigée pour l'orientation par défaut du faisceau vers le centre de la scène
  • panTilt null : les zones ne sont plus réinitialisées si aucun DMX n'a été écrit
