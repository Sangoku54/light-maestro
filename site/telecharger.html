Configuration requise

Windows 10 22H2 / 11, 4 Go RAM (8 Go recommandé), GPU WebGL2 pour la vue 3D, port USB ou réseau pour ArtNet/sACN.

Installation en 3 étapes

1) Télécharger 2) Lancer (autoriser SmartScreen si besoin : "Plus d'infos → Exécuter quand même") 3) Brancher votre interface DMX → tester avec Blackout.

Mises à jour

L'application vérifie les nouvelles versions au démarrage et propose la mise à jour. Conservez l'ancien .exe à côté jusqu'à ce que vous ayez validé le nouveau.

Notes de version — v1.0.46

  • Mises à jour automatiques fiabilisées : si le canal principal est momentanément indisponible, l'application bascule automatiquement sur le canal de secours. Une mise à jour ne peut plus être manquée parce qu'un fichier n'a pas été déposé sur le serveur.
  • Positions de fixtures cohérentes partout : le calcul DMX utilise désormais toujours les positions réelles de la scène (Performance et Quick Show), donc les limites de balayage restent identiques dans tous les modes.
  • Limites de balayage à source unique : la vue 3D et le moteur partagent le même code de clamp — plus aucune divergence possible entre le faisceau affiché et le faisceau envoyé au matériel.
  • Audit automatique des fixtures : chaque build est contrôlé pour vérifier que les canaux de chaque luminaire de vos projets (couleur, mouvement, rotation, intensité) sont bien alimentés, sans canal muet.
