Configuration requise

Windows 10 22H2 / 11, 4 Go RAM (8 Go recommandé), GPU avec WebGL2 pour la 3D Stage, port USB ou réseau pour ArtNet/sACN.

Installation en 3 étapes

1) Téléchargez 2) Lancez (autorisez le SmartScreen si besoin : “Informations complémentaires → Exécuter”) 3) Branchez votre interface DMX → testez avec Blackout.

Mises à jour

L'app vérifie les nouvelles versions au démarrage et vous propose la mise à jour. Gardez l'ancien .exe à côté le temps de valider le nouveau.

Notes de version — v1.0.39

Nouveau
  • Dupliquer une fixture : clic droit → Dupliquer, place automatiquement la copie à la première adresse DMX libre après la source (liste + carte DMX)
  • Positions musiciens persistantes : le drag d'un musicien sur le plateau 3D conserve sa position personnalisée entre les changements de page et réouverture du projet (stocké dans le roster)
Corrections
  • Thumbnails fantômes : nettoyage complet des sprites/groupes fixture au unpatch et unmount (plus de meshes orphanés dans la scène Three.js)
  • unpatchFixture : suppression correcte de l'entrée fixturePositions associée

  • panTiltRead null : les positions de zone ne sont plus écrasées quand aucun DMX n'a été écrit
Précédent — v1.0.38
  • Masters de Groupe : fader submaster par groupe dans la console — plafonne le dimmer, la dynamique du show reste vivante
  • Palettes de couleur réutilisables : application live en un clic + « Remplacer partout » propage une couleur à toutes les scènes (RGB ou roue)
