Release notes — v1.0.38

New
  • Group Masters: per-group submaster fader in the virtual console — caps the group dimmer while the show stays alive
  • Reusable Color Palettes: one-click live apply + "Replace everywhere" propagates a color to every scene (RGB or wheel)
  • MIDI Clock IN: BPM follows Ableton/Triton (24 PPQ) — hands back to analyzed BPM on stop
  • Projected gobos in 3D: per-slot textures, real DMX reading, disc inside the beam
  • Movement harmony: identical heads execute the same move, phased across the rig (wave, rotation, expansion)
  • Realistic 3D beams: fade along the beam, exact ground cutoff, real mechanical ranges (540°/360°… pan per fixture)
  • Sweep zones: pan never behind (engine clamp), ground tilt never below horizon — deliberate aims via Aim still allowed
  • RGB Matrix hardened: cell direction/offset, order = group order, off cells truly off, warning for incompatible fixtures
  • USB DMX plug & play: dongle auto-detected at launch, output started with zero configuration
  • DJ silhouette + 38 realistic fixture icons (wall washer, spider, follow spot, fresnel, derby…)
Fixes
  • Fixtures without a dimmer channel (ACCU UFO…): supported and flagged (NO DIM badge)
  • Programmer: values survive closing the modal
  • Multi-head LED: every head receives intensity (no more silent heads)
  • Wheel without white slot: correct neutral color instead of red
  • 3D scene empty by default (no stray trusses)
  • DMX engine at 60 fps: smooth pan/tilt in the 3D view
Previous — v1.0.37
  • Virtual console: Grand Master and DMX channel buttons, shared UI/MIDI/remote runtime
  • MIDI LED feedback: controller pads follow tile state
  • Safety: strobe ceiling + photosensitivity warning
  • Stopping pre-programmed scenes: real fixture blackout
