System requirements

Windows 10 22H2 / 11, 4 GB RAM (8 GB recommended), WebGL2-capable GPU for the 3D Stage, USB port or network for ArtNet/sACN.

Install in 3 steps

1) Download 2) Launch (allow SmartScreen if needed: “More info → Run anyway”) 3) Plug in your DMX interface → test with Blackout.

Updates

The app checks for new versions on startup and offers to update. Keep the old .exe alongside until you have validated the new one.

Release notes — v1.0.39

  • Duplicate fixture: right-click → Duplicate — auto-places copy at the first free DMX slot after the source (fixture list + DMX map)
  • Bar span control: adjustable support width (1–12 m) now defaults to all bar supports, not just frontBar/backBar raw matches
  • Persistent musician positions: dragging a musician on the 3D stage keeps the custom position across page switches and project reopen (stored in roster.positions)
  • No ghost thumbnails: full cleanup of fixture groups/sprites on unpatch and unmount
  • unpatchFixture: correctly removes associated fixturePositions entry
  • headingRadForPos: atan2 formula fixed for correct default beam orientation (stage center)
  • panTiltRead null: zone positions no longer overwritten when no DMX has been written

Previous — v1.0.38

  • Group Masters: per-group submaster fader in the virtual console — caps the group dimmer while the show stays alive
  • Reusable Color Palettes: one-click live apply + "Replace everywhere" propagates a color to every scene
  • MIDI Clock IN: BPM follows Ableton/Triton (24 PPQ)
