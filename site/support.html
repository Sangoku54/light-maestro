FAQ — les vraies questions de régie

DMX & réseau

Mon interface USB n'est pas détectée

Vérifiez : driver FTDI installé, bon port COM dans Univers → Type USB-DMX, un seul logiciel DMX ouvert à la fois, testez Blackout ON/OFF. Journal DMX dans l'app pour débug.

ArtNet / sACN : broadcast ou unicast ?

Unicast recommandé en prod (IP de votre node). sACN : vérifiez univers & priorité (HIGHEST gagne). ArtNet : subnet 0 par défaut, node en 2.x.x.x ou 10.x.x.x.

HTP/LTP : qui gagne ?

HTP = Highest Takes Precedence (intensités), LTP = Latest Takes Precedence (positions/couleurs). Light Maestro merge automatiquement par canal selon son type.

Audio & Quick Show

La détection de BPM est fausse

Re-analysez après avoir coupé les silences / intros longues, ou forcez le BPM (tap tempo). L'algo est adaptatif mais un morceau à tempo variable reste un challenge.

Strobe trop agressif

Safety limiter ON dans Quick Show (max flash/s), et piste Strobe dédiée avec plafond. En live : Grand Master ou Blackout instantané.

Fichiers .lmpreset / .lmshow / .lmproj ?

.lmpreset = preset audio+DMX, .lmshow = show réutilisable, .lmproj = projet complet (JSON ouvert).

MIDI / OSC / MTC / 3D

MIDI Learn ne capte rien

Fermez les autres apps MIDI, sélectionnez le bon port d'entrée dans Préférences → MIDI, puis Learn. Feedback LED = sortie MIDI configurée.

La vue 3D ne persiste pas par preset ?

Corrigé en v1.0.29 : caméra + toggles sont désormais sérialisés dans .lmpreset (view3D). Mettez à jour et re-sauvegardez vos presets.

Web Remote LAN

Activez le serveur dans Perform → Web Remote, ouvrez l'URL affichée sur votre téléphone/tablette du même réseau. Push d'état temps réel.

Projets & sauvegarde

J'ai fermé sans sauvegarder

Garde-fou “Save & Quit / Discard” à la fermeture. Si dirty, l'app vous demande.

Projet illisible sur une autre machine

Les fixtures customs sont embarquées dans le .lmproj depuis la v1.0.25 — plus de “fixture manquante”. Assurez-vous d'être en ≥1.0.25 des deux côtés.

Où sont mes fichiers ?

%APPDATA%/Light Maestro (Windows) — projets, presets, logs. Sauvegardez ce dossier pour backup complet.
